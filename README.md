# Keitaro Workbench

Тестовое задание для «Это Легко». Приложение создаёт кампании в Keitaro и позволяет редактировать распределение трафика по офферам.

## Запуск

Понадобятся Python 3.12+ и [uv](https://docs.astral.sh/uv/getting-started/installation/). Из корня репозитория выполните:

```sh
uv sync --locked --python 3.12
uv run --locked alembic upgrade head
uv run --locked uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте [интерфейс](http://127.0.0.1:8000/) или [Swagger UI](http://127.0.0.1:8000/docs). При первом запуске без .env доступен демо-режим с кампанией №2401, пятью офферами и синтетической статистикой. Миграция создаёт таблицы в локальной SQLite. Для просмотра текущей версии схемы используйте `uv run --locked alembic current`.

### Подключение к Keitaro

Скопируйте `.env.example` в `.env` и заполните три параметра:

```dotenv
DEMO_MODE=false
KEITARO_BASE_URL=https://your-tracker.example
KEITARO_API_KEY=your-admin-api-key
```

Укажите адрес трекера без пути `/admin`. Ключ Admin API используется на сервере и хранится в локальном .env. Запустите миграцию ещё раз и перезапустите приложение. По умолчанию демо использует `demo.sqlite3`, а режим Keitaro — `workbench.sqlite3`.

Группа и источник по умолчанию выбираются по имени `FORTESTS`, если оно есть в справочнике. Единственный доступный домен выбирается автоматически. Значения можно переопределить через `DOMAIN_ID`, `GROUP_ID`, `TRAFFIC_SOURCE_ID` или выбрать в форме. Отчёты по умолчанию строятся в `Europe/Moscow`. Для другого часового пояса задайте `REPORT_TIMEZONE`.

## Что проверить

1. **Создание кампании.** Укажите название, двухбуквенный гео-код и оффер. Проверьте домен, группу и источник. Имя автоматически получает префикс `test_pechenov_`. Keitaro сначала проверяет поток с фильтром страны и редиректом на Google. Остальной трафик попадает в поток по умолчанию, где выбранный оффер получает 100%.
2. **Редактор.** Откройте кампанию из списка или по её ID. В демо введите ID оффера `104` и добавьте его к трём стартовым офферам. Получится четыре доли по 25%. Закрепите 25% у №101 и удалите №103. У остальных офферов будут доли 38% и 37%.
3. **Публикация и архив.** Нажмите «Отправить в Keitaro» и обновите страницу. Оффер №103 останется в архиве с долей 0%. Кнопка «Вернуть» добавит его обратно в черновик. При обновлении кампании ранее загруженные офферы, удалённые напрямую в Keitaro, также попадают в архив. «Отменить» возвращает последнюю сохранённую конфигурацию, в том числе при конфликте с изменениями в Keitaro.
4. **Статистика.** Переключите период и сравните клики, конверсии и продажи. В режиме Keitaro данные берутся из `POST /report/build` и группируются по потоку, офферу и дню. Клики в потоке с редиректом входят в итог кампании. Успешный пустой отчёт отображается нулями, ошибка загрузки обозначается прочерками.

## Реализация

- FastAPI, SQLAlchemy и Alembic. Интерфейс на HTML, CSS и JavaScript без отдельной сборки.
- Keitaro хранит кампании, потоки и отчёты. SQLite хранит черновики, закреплённые доли, историю состава потоков и состояние запроса на создание.
- Кампания создаётся отключённой и включается после проверки обоих потоков. Повтор запроса с тем же `request_id` продолжает создание после сбоя. В форме этот идентификатор сохраняется при повторной отправке тех же параметров.
- Публикация отправляет в Keitaro состав офферов одного потока. Если ответ на запись потерялся, повторное действие сначала сверяет текущий состав с черновиком. Локальные операции записи выполняются последовательно. Используйте один процесс Uvicorn, как в команде запуска.

Контракт интеграции описан в [Keitaro Admin API](https://admin-api.docs.keitaro.io/).

## Проверки

```sh
uv run --locked pytest -q
uv run --locked ruff check
uv run --locked ruff format --check
uv run --locked alembic check
```

Тесты проверяют восстановление создания после потери ответа, входные данные, черновики, распределение долей, архив, конфликты и агрегацию статистики. На тестовом стенде через Admin API проверены создание и включение кампании, состав двух потоков, удаление и восстановление доступного оффера и загрузка отчёта.
